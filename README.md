## 📖 About DevDock

**DevDock** is a high-performance desktop application engineered to streamline local web development. Designed for modern developers working with frameworks like **Laravel**, **Vite**, **PHP**, and **Node.js**, DevDock eliminates port collisions, automates reverse proxying, and provides unified service orchestration in a native desktop interface.

### ✨ Key Capabilities

- 🚀 **Portless Local Reverse Proxy**: Automatic domain mapping (e.g. http://my-app.test) without manual hosts file editing or port juggling.
- ⚡ **Process Supervisor**: Seamless lifecycle management for dev servers, queue workers, and background watchers.
- 📬 **Built-in Mail Sandbox**: Capture and inspect outgoing transactional emails locally in real-time.
- 🧪 **Interactive Tinkerpad**: Execute and test code snippets in isolated project runtimes.
- 🔄 **Autonomous Auto-Updates**: Silent background download with cryptographically signed release packages.
- 🎨 **Modern Native UX**: Fluid, responsive interface built with React 19, Tailwind CSS, and Rust.

## 📥 Downloads & Installation

### Windows Installation

1. Navigate to the **[Latest Release Assets](https://github.com/tljafar/devdock-releases/releases/latest)**.
2. Download the installer:
   - **DevDock_*_x64-setup.exe** (Standard Windows NSIS Installer — *Recommended*)
   - **DevDock_*_x64_en-US.msi** (Windows MSI Package)
3. Launch the installer and follow the setup wizard.
4. DevDock will automatically check for and install future updates in the background.

## 🔐 Security & Verification

All official DevDock release binaries and update bundles are cryptographically signed using an **Ed25519** keypair to ensure tampering resistance:

- Every release includes signature metadata (.sig) validated by DevDock's updater before execution.
- Checksums and release hashes are published alongside each release in the [Releases tab](https://github.com/tljafar/devdock-releases/releases).
